## 🔐 Security Considerations

The portfolio itself is a static front-end website and does not process sensitive user information.

When linking external services or APIs:

* External links use appropriate security attributes.
* API keys should not be exposed unnecessarily.
* Sensitive credentials should never be committed to GitHub.
* Environment variables should be used for projects that require private credentials.

For example, sensitive configuration should not be committed:

```text
.env
```

Instead, provide a safe example configuration such as:

```text
.env.example
```
